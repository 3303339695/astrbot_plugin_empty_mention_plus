# 空 @ 接话

只 @ 或只发唤醒词时，也能像“正常内容 + @”一样，带着完整上下文让模型回答。

## 处理规则

- **只 @**：把这条消息改写成“@机器人 + 一句话”的普通形状，走正常流程，
  完整上下文一起交给模型；不再塞固定提示词；
- **只发唤醒词**：同样走正常流程，把唤醒词本身作为这一句，完整上下文一起带上；
- **带内容的唤醒词**：把被框架剪掉的唤醒词补回消息，避免“为什么”变成“天空是蓝的”；
- **带 @ 的正常内容**：照旧去掉 @，不额外处理；
- **等待**：回答完后仍然等六十秒；只认刚才那个人，同群别人说话不会被抓走。

## 和上一版的区别

上一版只把“@番茄酱”本身交给模型，没有带上下文，等于只换了提示词。
这一版改成把空 @ 重新摆成普通消息，让正常流程自己带完整对话上下文，
效果接近“正常内容 + @”。

## 安装后要做的

1. 导入安装包；
2. 在“配置文件 → 平台配置 → 基本 → 可用插件”里勾上“空@接话”，保存；
3. 先发一句问题，再单独 @ 一下，看模型是否能接着上下文回答；
4. 也可以只发唤醒词测试。

原来那个“只 @ 机器人是否触发等待”的开关，开不开都行；这个插件会在它前面接管。

## 配置

- 保留 @：只 @ 时这一句是“@称呼”还是只给“称呼”；
- 称呼兜底：消息里拿不到机器人昵称时用的名字，例如“召唤”；
- 等待秒数：默认六十秒；
- 补回唤醒词：带内容的消息是否补回被剪掉的唤醒词。

## 注意

- 如果导入过旧版本，先在插件页删掉旧的，再导入这个新版。
- 等待期间发指令会作为新消息重新处理，不会被当成接话内容。
- 不要和其他接管空 @ / 唤醒流程的插件一起开，容易叠两层等待。
